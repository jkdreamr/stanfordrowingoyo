# Integrated territory-consistency review

Rule: a country-with-X predicate uses the country's own metropolitan/integral territory, not its dependencies, unless the visible question explicitly says otherwise. Integral islands/exclaves are not automatically dependencies. Review date: 9 November 2026. Overlap is informational only.

## Changes

- Mediterranean membership: **24 → 23**. Remove United Kingdom and its four canonical/alias forms. France remains via mainland/Corsica. The original batch-2 raw and selected brainstorms have **no UK guess**, so no historical guess was relabelled: four explicit, source-backed negative fixtures were added in `refine-territories-selected.json` and appended by the evaluator.
- France borders: the pre-existing acceptance note already allowed overseas/disputed borders, but the visible question did not. Make the overseas exception visible; retain all members.
- Island countries: acceptance notes erroneously said Australia counts while the pinned source and 50-member data exclude it as continental. Correct the notes, not the answer list.
